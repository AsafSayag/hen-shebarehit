# סקיצות לוגו

`identity/` מכילה את הפיתוח העדכני עבור **החן שברהיט**: סמל סלון מצומצם ב־SVG, לוגו ראשי שקוף וגרסה קומפקטית לכותרת אתר.

`living-room/02-interior-sketch-logo-v3.png` היא הסקיצה המאוירת שממנה פותח הסמל.

`boutique/` מכילה סקיצות טיפוגרפיות קודמות שנדחו. הקבצים בשורש התיקייה וב־`refined/` כוללים שם עסק שגוי. אין להשתמש בקבצים הישנים באתר.
